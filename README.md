# Telegram-бот и Mini App «Аудитор сделок» (Deal Auditor) — PROD v1.1.0

Сервис для селлеров цифровых товаров (**Plati.market, Digiseller, Playerok, FunPay**). Рассчитывает реальную чистую прибыль, маржинальность, точку безубыточности, подбирает витринную цену и проводит **пакетный аудит сотен товаров из CSV**.

---

## Ключевой функционал

1. **⚡ Одиночный аудит сделки (Forward Calculation):**
   - Точный учёт комиссий площадки, вывода средств и налогов (НПД 4/6%, УСН 6/15% или без налога).
   - Точка безубыточности ($Price_{min}$) и максимально допустимая скидка.
   - Четкие вердикты: **🟢 Выгодно**, **🟡 На грани**, **🔴 Убыток**.
2. **🎯 Подбор витринной цены (Reverse Calculation):**
   - Расчёт необходимой цены лота под желаемую чистую прибыль (например, `+300 ₽ чистыми`) или желаемый % маржи.
3. **📁 Массовый расчёт и аудит из CSV (Bulk Processing):**
   - Загрузка любого прайс-листа в формате `.csv` (поддержка разделителей `;`, `,`, русских заголовков и запятых в числах `18,5`).
   - Автоматический валютный пересчет закупки в **TRY, USDT, USD, EUR, KZT, RUB**.
   - Сводные KPI каталога: суммарная чистая прибыль портфеля, средняя маржа, выявление всех позиций с убытком.
   - Фильтрация лотов в 1 клик (*«Только в убыток 🔴»*).
   - Выгрузка готового аудита с рекомендациями обратно в `.csv` для Excel.
4. **🤖 Пакетный аудит прямо в Telegram:**
   - Просто отправьте файл `.csv` боту в диалог — бот пришлет сводку, список убыточных лотов и готовый обработанный CSV-файл.
5. **🌐 Telegram Mini App (TMA):**
   - Одностраничный интерфейс с вкладками, тактильной отдачей и темной темой Telegram.
6. **💎 Подписочная модель и интеграция с Playerok:**
   - Модель монетизации по ежемесячной подписке (30 дней).
   - Автоматическая выдача ключей активации формата `AUDIT-XXXX-XXXX-XXXX`.
   - Встроенный 3-дневный бесплатный триал для новых пользователей.
   - Команды: `/sub` (статус), `/activate КЛЮЧ` (активация), `/genkey [кол-во] [дней]` и `/grant [id] [дней]` (для админа).

## Быстрый старт (Локально)

### 1. Запуск в браузере:
```bash
# Активация окружения
.venv\Scripts\activate

# Запуск сервера
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
Откройте в браузере: **[http://localhost:8000](http://localhost:8000)**.

### 2. Подключение к Telegram:
1. Создайте бота через [@BotFather](https://t.me/BotFather) и вставьте токен в [`.env`](.env):
   ```env
   BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRstuVWXyz
   ```
2. Для мобильного Mini App пробросьте HTTPS (например, через `npx localtunnel --port 8000` или `ngrok http 8000`) и укажите адрес в `WEBAPP_URL`.
3. Запустите сервер — бот подхватит токен и начнёт приём сообщений.

## Развертывание в Production (Docker)

В репозиторий включены оптимизированные [Dockerfile](Dockerfile) (multi-stage, non-root `appuser`) и [docker-compose.yml](docker-compose.yml):

```bash
# Запуск через Docker Compose
docker compose up -d --build
```
База данных SQLite монтируется в том `./data/deals.db` и сохраняется при перезапусках.

```bash
.venv\Scripts\pytest -v
```

- Математику комиссий, вывода и налогообложения
- Валютную конверсию и обратный расчёт
- Парсинг CSV с различными кодировками, разделителями и форматами чисел
- Пакетную аналитику и выгрузку отчетов
- Все REST API эндпоинты
